## Словари (`dictionaries`) — источник истины
Автор правит таблицу — сервис подхватывает без деплоя (синхронизация раз в 6 ч и по кнопке в админке — фаза 10; до этого — `dictionaries/seed/` в репо).

| Лист | Колонки | Пример |
|---|---|---|
| `swear_words` | `word`, `category` (мат / грубое / исключить) | ~2000 форм из `bad_words.txt` автора |
| `swear_patterns` | `id`, `pattern` (регулярка по корню), `display` (с маской), `enabled` | `1`, `ху[йеёяию]`, `х*й`, `TRUE` |
| `swear_exceptions` | `word` | `страхуй`, `психуй` |
| `names` | `id`, `base`, `gender`, `variants` (через запятую), `ambiguous`, `enabled` | `alexandr`, `Александр`, `m`, `Саша, Саня, Шура` |
| `laugh` | `pattern`, `enabled` | `(?:а?х+[аеыи]+){2,}х*` |
| `stopwords` | `word` | `это`, `просто` |
| `safe_words` | `word` | безобидные слова для проверки паттернов |

- **Имена:** для базы и каждого варианта сервер генерирует падежные формы (pymorphy3 + окончания). `ambiguous`: «Вера» — исключить слово целиком; «=кости» — исключить одну форму (у «Костя» форма «кости» совпадает со словом). Стартовый список (~110 имён с уменьшительными) — `dictionaries/seed/names.csv`.
- **Мат:** точные формы (`swear_words`) + корни (`swear_patterns`) − исключения. Каждой форме сервер назначает группу (первый подходящий корень), в отчёте — маска «х*й».
- **Валидация:** регулярки компилируются; паттерн, задевающий слово из `safe_words` (не из исключений), — ошибка → версия не активируется, админ получает список ошибок; работает последняя валидная.
- Версия словаря пишется в каждый разбор.

## Журналы (`ops_log`) — зеркало для удобного просмотра
Описание листов — [22-data-access.md](22-data-access.md). Запись — через `sheets_outbox` пачками раз в минуту (`flush_outbox`), лист `users` — снимок раз в 10 минут (`write_users_snapshot`). Без ключей сервисного аккаунта задачи пропускаются (в логах `sheets.skip_not_configured`). В таблицу пишется `user_ref`, не email (152-ФЗ).
