# Дизайн-система stats_tt_tg

Первой строкой ответа: `🔧 Скилл: design-system — <зачем>`.

Источник правды — `docs/12-design-system.md`. Перед работой перечитай его. Ключевое:

## Делай
- Только семантические CSS-переменные из `packages/design-tokens` (`--bg`, `--text`, `--accent`, `--series-N`, `--seq-N`). Никаких захардкоженных hex в компонентах и шаблонах.
- Шрифты: Unbounded (дисплей/крупные числа), Onest (текст), JetBrains Mono (цифры, таблицы). `tabular-nums` для чисел.
- Заголовок над графиком — вывод с числом («Вы пишете первой в 64% случаев»), а не название графика.
- Числа по-русски: `48 312` (неразрывный пробел), `3,4`, даты «14 фев 2025», дни «пн…вс».
- Сетка 8px, контейнер ≤ 1120px, текст ≤ 680px, mobile-first (360 / 768 / 1280).
- Линии 1px, сетка графика еле заметная, без теней у карточек.
- Каждый экран проверяй во всех палитрах: Бумага, Графит, Мох, Терракота, Сумерки, Плёнка (светлые и тёмные варианты).
- Для графиков дополнительно загрузи скилл `dataviz`; цвета участников стабильны: p0 → series-1, p1 → series-2.

## Не делай (антипаттерны)
- Фиолетово-синие градиенты, «стеклянные» карточки, неоновые свечения.
- Скругления 20–32px на всём подряд (у нас 6/10/16).
- Эмодзи как иконки интерфейса.
- Карточки-в-карточках, лишние бордюры, тени под каждым блоком.
- Круговые диаграммы для > 3 долей; 3D; радуга из 7 цветов для дней недели (будни нейтральные, выходные — акцент).
- Готовые UI-киты (MUI, Ant, shadcn-стиль по умолчанию). Radix — только как поведение.
- Центрирование всего текста; крупные пустые hero с абстрактной графикой.

## Проверка перед сдачей
1. Скриншоты Playwright на 360 и 1280 в светлой и тёмной теме — посмотри их сам (Read картинки).
2. Нет горизонтального скролла страницы.
3. Контраст текста AA во всех палитрах (скрипт в `packages/design-tokens`).
4. Фокус виден с клавиатуры; `prefers-reduced-motion` уважается.
