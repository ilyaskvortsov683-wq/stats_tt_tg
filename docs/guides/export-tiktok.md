# Как выгрузить данные из TikTok

> TikTok готовит архив не сразу — обычно от нескольких часов до 1–2 дней. После готовности файл доступен для скачивания ограниченное время (несколько дней) — **включите напоминание в нашем боте**, чтобы не пропустить.
>
> ⚠️ В выгрузке есть история просмотров только примерно **за последние 6 месяцев**. Сохраняйте свои выгрузки (например, в «Избранном» Telegram) или включите у нас хранение истории — тогда статистика будет копиться за всё время.

*(Точные названия пунктов меню сверить с актуальной версией приложения перед публикацией.)*

## Шаг 1. Профиль → ☰ (меню справа вверху)
*Скриншот.*

## Шаг 2. «Настройки и конфиденциальность»

## Шаг 3. «Аккаунт» → «Скачать свои данные»

## Шаг 4. Выберите данные и формат
- Какие данные: **Все данные** (или как минимум «Активность» и «Личные сообщения»).
- Формат файла: **JSON** — обязательно (TXT не подойдёт).
- Нажмите **«Запросить данные»**.
*Скриншот: экран выбора формата JSON.*

## Шаг 5. Включите напоминание
В нашем боте нажмите **«Я запросил выгрузку»** — напомним через сутки.

## Шаг 6. Скачайте архив
Тот же экран → вкладка **«Скачать данные»** → «Скачать». Может потребоваться подтвердить вход.

## Шаг 7. Загрузите файл
Внутри архива — файл вроде **user_data_tiktok.json**. Загрузите его на сайт (можно сразу несколько старых выгрузок) или отправьте боту. Несколько файлов можно переслать боту **одним сообщением** — мы их склеим.

### Через браузер на компьютере
tiktok.com → аватар → Настройки → Конфиденциальность → «Скачать свои данные» — шаги те же.
