# 11. Интерфейс и сценарии

> Перед работой загрузить скилл `design-system`. Вид — по docs/12.

## Карта экранов
```
/                    лендинг: суть, пример отчёта, приватность, цена, «Войти через Google»
/sample              пример отчёта (синтетический, docs/report-sample.md)
/app                 рабочее пространство: вкладки [Telegram] [TikTok], баланс в шапке
  /app/tg            загрузка → бесплатные сводки → выбор сводок → разбор
  /app/tt            загрузка (одна или несколько выгрузок) → история → сводки → разбор
/app/reports         мои отчёты
/app/reports/:id     отчёт (iframe серверного HTML) + панель экспорта
/app/billing         пакеты, промокод, история движений
/app/settings        тема и палитра, часовой пояс, Telegram, хранение истории, удалить аккаунт
/admin/*             админка (docs/15)
/tg                  Mini App
/legal/{offer,privacy}
```

## Вкладка Telegram — шаги
1. **Загрузка.** Зона «Перетащите result.json» + кнопка **«Как выгрузить чат?»** (открывает гайд в боковой панели/шторке на мобильном). Подпись: «Файл не покидает ваше устройство».
2. **Разбор файла** в воркере с прогрессом (прочитано МБ / сообщений). Полный экспорт → выбор чата из списка.
3. **«Кто из них вы?»** (для личек, запоминается).
4. **Бесплатно сразу:** KPI «Всего сообщений», полосы по участникам, период. Кнопка «Поделиться карточкой» (PNG, генерируется в браузере).
5. **Выбор сводок:** список карточек-чекбоксов со значком и одной строкой «что внутри», мини-превью; замок на платных; «Выбрать всё». Для `tg.words`/`tg.names` — поля ввода своих слов/имён. Внизу: «Сделать разбор — спишется 1 из 4 разборов» или «Повтор бесплатно (обновление отчёта от 12.09)».
6. **Прогресс разбора** (SSE): «Собираем пакет → Отправляем 84 КБ → Считаем → Рисуем».
7. **Отчёт** + панель экспорта: HTML / PDF / PNG-карточки / длинный PNG; выбор темы для экспорта.

## Вкладка TikTok — отличия
- Загрузка **нескольких файлов сразу** (мульти-выбор, zip поддерживается).
- Галочка «Сохранять историю просмотров для склейки» (вкл. по умолчанию, пояснение «TikTok отдаёт только последние ~6 месяцев»).
- После загрузки: «В вашей истории 61 245 просмотров с 03.2025 по 05.2026 (3 выгрузки)».
- Бесплатно: итог просмотров и таблица чатов со счётчиками.
- Выбор сводок + **выбор одного чата** для `tt.chat_deep` (список чатов с числами).
- Кнопка «Напомнить о выгрузке в Telegram» (если бот привязан).

## Гайды экспорта
- Кнопка на каждой вкладке и в лендинге. Компонент «степпер»: шаг N из M, картинка (скриншот), короткий текст, «Дальше». Платформенные ветки: Telegram — только десктоп (Windows/macOS/Linux); TikTok — iOS/Android/веб.
- Контент — `docs/guides/*.md` → при сборке превращается в JSON (фронтматтер с шагами). Скриншоты — в `apps/web/public/guides/` (готовит автор, место под них предусмотрено).

## Состояния и тексты
- Пустые, загрузка, ошибка для каждого шага. Ошибки человеческим языком + код `request_id` мелко.
- Неподдерживаемый файл: «Это не похоже на экспорт Telegram. Нужен файл result.json в формате JSON (машиночитаемый)».
- Большие файлы: предупреждение > 500 МБ, предложение снять галочку «медиа» при экспорте.

## Адаптивность и доступность
- Mobile-first, контрольные ширины 360 / 768 / 1280. Нет горизонтального скролла.
- Таблицы на мобильном — карточками или с липкой первой колонкой.
- Фокус-стили, контраст AA, `prefers-reduced-motion`.

## Переключатель темы
В шапке: ☀ светлая / ☾ тёмная / 🎨 палитры (выпадающая сетка с превью). По умолчанию — системная. Выбор хранится в профиле и `localStorage`.
