# 00. Видение проекта

## Что это

Сервис, который превращает экспорт переписки или данных аккаунта в красивый статистический разбор.

- **Источники:** Telegram (`result.json` из Telegram Desktop) и TikTok (выгрузка «Download your data» в JSON).
- **Каналы:** веб-приложение (основное, вход через Google, резервный — через Telegram) и Telegram-бот (второй вход, напоминания, оплата звёздами).
- **Модель:** бесплатные базовые счётчики → платные подробные **разборы**, пакет «5 разборов за 200 ₽».
- **Цель автора:** пассивный доход; сервис работает автономно, автор надзирает через админку, логи и Google-таблицу.

## Принципы

1. **Тексты переписок не покидают устройство** (на сайте). Браузер считает бесплатное и собирает обезличенный пакет. Через бота файл обрабатывается на сервере в памяти и сразу удаляется (пользователь предупреждается).
2. **Платная часть защищена сервером.** Платные метрики и отчёт строятся только на сервере.
3. **Пользователь сам выбирает сводки** галочками до запуска; **в готовом отчёте в любой сводке можно выбрать любой период** (по умолчанию — весь период экспорта).
4. **История просмотров TikTok копится у нас** (по согласию): TikTok отдаёт ~6 месяцев, новые выгрузки склеиваются со старыми. Несколько файлов можно загрузить разом (на сайте или одним сообщением в бота).
5. **Время — в поясе пользователя.** Спрашиваем город (по умолчанию — пояс браузера). Telegram хранит точное UTC-время каждого сообщения, TikTok пишет время в UTC.
6. **Без ML.** Статистика, регулярки, словари. Словари мата и имён автор правит в Google-таблице без деплоя.
7. **Красиво, а не «нейросетево».** Собственная дизайн-система: светлая, тёмная и пять палитр.
8. **Подробные логи** всего, кроме содержимого переписок.
9. **Админу всё бесплатно.**

## Глоссарий

| Термин | Значение |
|---|---|
| **Разбор** | Единица оплаты (мн. — «Разборы»). Telegram: 1 разбор = 1 чат. TikTok: 1 разбор = история просмотров + активность + 1 выбранный личный чат. |
| **Пакет «5 разборов»** | 200 ₽ (или 150 ⭐ в боте) → 5 разборов на балансе, тратятся в любой вкладке. |
| **Сводка** | Блок отчёта («Часы и дни», «Монологи и диалоги»…). Выбирается галочкой. |
| **Пакет агрегатов** | Обезличенный JSON со счётчиками, который браузер отправляет на сервер. Без текстов. |
| **Модель отчёта (report.v1)** | Факты с точностью до дня, из которых отчёт пересчитывает любую сводку за любой период. |
| **Отпечаток чата** | `sha256(user_id + источник + id чата)`. Повтор того же чата 30 дней бесплатен. |
| **Склейка** | Объединение выгрузок TikTok; дубли — по паре (время, видео), повторные просмотры сохраняются. |
| **Монолог** | Сообщения одного человека подряд (перерывы ≤ 30 мин). Самые длинные — по сообщениям и по словам. |
| **Разговор (диалог)** | Непрерывная переписка обоих (перерывы ≤ 30 мин). Самые длинные — по времени, сообщениям, словам. |
| **Журнал (ledger)** | Неизменяемая таблица движений разборов. |
| **user_ref** | Псевдоним пользователя для логов и Google-таблицы вместо email. |

## Ключевые решения

| Вопрос | Решение | Документ |
|---|---|---|
| Налоговый режим | Самозанятость (НПД) на старте; при росте — ИП | 21, OPEN-QUESTIONS |
| Оплата | ЮKassa на сайте (v1), Telegram Stars в боте; Робокасса — запасной вариант | 09, 21 |
| Вход | Обязателен. Google основной, Telegram — резервный | 08 |
| Хостинг | Один VPS в РФ (Docker Compose); Vercel/Netlify — нет | 19 |
| Хранение ПД | PostgreSQL в РФ; в Google Sheets — только `user_ref` | 16, 18, 22 |
| Где смотреть данные | Админка + зеркало в Google-таблице `ops_log` | 22 |
| Технические логи | На VPS с ротацией + ежедневный архив на Google Диск автора | 14 |
| Словари | Google-таблица на Диске; копия-заглушка в репо | 16 |
| Отчёт | Самодостаточный HTML: модель + встроенный JS, выбор периода в любой сводке | 13 |
| Содержание тиктоков | Только метаданные через публичный oEmbed (бета) | 17 |
| TikTok-сессия | Новая сессия после перерыва > 10 минут | 04 |
