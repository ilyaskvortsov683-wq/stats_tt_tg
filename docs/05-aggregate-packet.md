# 05. Пакет агрегатов (браузер → сервер)

Контракт между сборщиком в браузере (TS), сборщиком в боте (Python) и платными метриками на сервере. JSON Schema — `packages/schema/packet.v1.json`; из неё генерируются TS-типы и pydantic-модели.

## Принципы
- **Никаких текстов сообщений.** Ни целиком, ни фрагментами. Только числа, даты, имена участников, эмодзи, названия источников пересылок, названия беседы и топ-слова (после стоп-слов, только слова длиной ≥ 3, топ-200 на участника).
- Включаются **только блоки выбранных сводок**.
- Участники передаются как `p0, p1, …`; отображаемые имена — отдельным полем `participants` (пользователь может включить «Скрыть имена» → «Участник A/B»).
- Время — локальные unix-секунды (как в экспорте).
- Размер: десятки–сотни КБ после gzip. Лимит приёма: 5 МБ (сжатый).

## Структура v1

```jsonc
{
  "schema": "packet.v1",
  "run_id": "r_…",
  "source": "tg",                       // tg | tt
  "chat_kind": "personal",               // personal | group | account
  "sections": ["tg.rhythm", "tg.clock", "tg.laugh_swear"],
  "participants": [{"key": "p0", "name": "Аня", "is_owner": true}, {"key": "p1", "name": "Кирилл"}],
  "tz": "Europe/Moscow",
  "dict_versions": {"swear": "2026-10-01.3", "names": "2026-10-01.3"},

  // Базовый поток: по одному элементу на сообщение, БЕЗ текста.
  // Компактно: колоночный формат (массивы одинаковой длины).
  "stream": {
    "ts":      [1735814710, …],
    "author":  [0, 1, …],                 // индекс участника
    "kind":    [0, 3, …],                 // индекс в словаре kinds
    "dur":     [null, 12, …],             // длительность медиа
    "fwd":     [null, 2, …],              // индекс источника пересылки
    "words":   [5, 0, …],                 // число слов
    "laugh":   [0, 1, …],                 // 1 если есть смех
    "swear":   [0, 2, …]                  // число матерных совпадений
  },
  "kinds": ["text", "voice", "video_note", "photo", "sticker", …],
  "forward_sources": ["Канал X", …],

  // Блоки по сводкам
  "words": { "top": { "p0": [["привет", 312], …], "p1": […] }, "custom": {"россия": {"p0": 3, "p1": 1}}, "mask": {…} },
  "laugh_forms": [["ахах", 230], …],
  "swear_roots": { "p0": {"root_17": 40}, "p1": {…} },     // корни по id словаря, не слова
  "names": { "p0": {"name_3": 18}, … },                     // id базового имени из словаря / пользовательского списка
  "names_by_month": { "2025-03": {"name_3": 4} },
  "reactions": { "total": {"❤": 512}, "by_day": {"2025-03-01": 7}, "who_whom": [[0, 1, 140]] },
  "emoji": { "p0": {"😂": 300} },
  "stickers": [["😂", "file_hash_8", 41]],
  "events": [{"ts": …, "actor": 0, "action": "title", "title": "Беседа века"}],

  // TikTok
  "tt": {
    "history_ref": "h_…",               // история просмотров уже на сервере (docs/02 §2.3)
    "likes": [ts…], "favorites": [ts…], "collections": [ts…], "logins": [ts…],
    "chat": { "partner": "some_user", "stream": { "ts": […], "author": […], "is_share": […] } }
  },

  "client": { "app_version": "1.4.0", "parser_version": "tg-1.2", "build_ms": 840 }
}
```

## Что считается в браузере, а что на сервере

| Действие | Где | Почему |
|---|---|---|
| Парсинг, нормализация | браузер | файл не уходит |
| Токенизация, стоп-слова, топ-200 | браузер | нужен текст |
| Совпадения со словарями (мат/имена/смех) | браузер, словари из `ticket` | нужен текст |
| Временные ряды, сессии, диалог, тепловые карты, медиа, все выводы | **сервер** | платная логика |
| Отрисовка отчёта | **сервер** | платная логика |

## Валидация на сервере
- Версия схемы, размеры массивов, монотонность `ts` (допускается сортировка на сервере), пределы (≤ 2 млн сообщений, ≤ 500 участников).
- `sections` ⊆ сводок, зарезервированных в `POST /runs`.
- Ошибка валидации → разбор не списывается, событие `packet.invalid` с причиной (без содержимого).
