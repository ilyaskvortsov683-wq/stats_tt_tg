# 11. Интерфейс и сценарии

> Перед работой — скилл `design-system`. Вид — docs/12.

## Карта экранов (v0.1)
```
/                лендинг: суть, 3 факта, как это работает, выбор темы, гайды
/login           вход: согласие + Google / Telegram / dev-вход локально
/sample          пример отчёта (синтетика, настоящий рендер), Telegram/TikTok
/app/tg          Telegram: файл → (выбор чата) → кто вы + город → бесплатно → галочки → разбор
/app/tt          TikTok: файлы (можно несколько) → город, согласие на историю → бесплатно → галочки, чат → разбор
/app/reports     мои отчёты + сохранённые моменты
/app/reports/:id отчёт в iframe, «Открыть отдельно», «Скачать HTML», PDF/PNG (скоро), окно «Текст» момента
/app/billing     баланс, пакет, промокод, история; тестовая оплата локально
/app/settings    город, тема и палитра, Telegram, история TikTok, выход, удаление
/admin           обзор, пользователи, промокоды, разборы, журнал
/tg, /legal/*    заглушки Mini App и юр. страниц
```

## Telegram — шаги
1. Зона загрузки + «Как выгрузить чат?» (гайд-степпер). Подпись: файл не покидает устройство.
2. Разбор в воркере; полный экспорт → выбор чата.
3. «Кто из них вы?» (личка) и **город** (по умолчанию из профиля/браузера; подсказка про пояс устройства экспорта).
4. Бесплатно: всего сообщений, у каждого (полосы), период, активные дни.
5. Галочки сводок + поля «свои слова/маски» и «свои имена», «Скрыть имена».
6. Кнопка «Сделать разбор — спишется 1 из N» (админ — бесплатно) → этапы: резерв → пакет → отправка (КБ) → расчёт → отчёт.

## TikTok — отличия
Несколько файлов сразу (склейка в браузере + на сервере); согласие «Хранить историю» (по умолчанию включено, с пояснением — проверить у юриста, см. OPEN-QUESTIONS); бесплатно — просмотры и таблица чатов; выбор чата для «Разбора чата».

## Отчёт
Период — в шапке для всего отчёта и у каждой сводки свой («◷ Период»): кнопки «Весь период / Год / 3 месяца / 30 дней» и даты «с — по»; «Как у отчёта» сбрасывает. Тема и палитра — в шапке отчёта. «Текст» у монологов и разговоров открывает окно с сообщениями из файла (если файл загружен в этой вкладке), кнопки «Сохранить в файл» и «В избранное».

## Состояния
Ошибки человеческим языком (+ код запроса), пустые состояния, прогресс. Не JSON / не тот экспорт / zip — понятные подсказки.

## Адаптивность и доступность
Mobile-first, 360/768/1280, без горизонтального скролла, таблицы прокручиваются внутри блока, фокус виден, `prefers-reduced-motion`.

## Фаза 3+
Бесплатная PNG-карточка, потоковый парсинг больших файлов, zip, предпросмотр сводок, онбординг.
