# 16. Google: Sheets (журналы) и Drive (словари)

## Общая настройка (фаза 0, делает автор с помощью Claude)
1. Google Cloud проект `stats-tt-tg`: включить Google Sheets API, Google Drive API; OAuth consent screen (для входа пользователей).
2. Сервисный аккаунт `bot@…iam.gserviceaccount.com`, JSON-ключ → в секреты сервера (не в репо).
3. На Google Диске автора папка проекта:
```
stats_tt_tg/
  dictionaries      (Google-таблица со словарями)
  ops_log           (Google-таблица журналов и статистики)
  design/           (макеты, скриншоты для гайдов, шрифты — не ПД)
  samples/          (образцы экспортов автора — только для разработки; ПД! доступ только автору)
```
4. Поделиться таблицами `dictionaries` (чтение) и `ops_log` (редактирование) с сервисным аккаунтом.

## Словари (`dictionaries`, источник истины)
Автор редактирует словари прямо в таблице — без кода и деплоя.

| Лист | Колонки | Пример |
|---|---|---|
| `swear` | `id`, `pattern` (регулярка по корню, без `^$`), `display` (с маской), `weight`, `enabled` | `17`, `ху[йеёяю]\w*`, `х*й`, `1`, `TRUE` |
| `swear_exceptions` | `word` | `страхуй`, `хулиган` |
| `names` | `id`, `base`, `gender` (m/f), `variants` (через запятую: уменьшительные и прозвища), `enabled` | `3`, `Александра`, `f`, `Саша, Сашка, Сашенька, Шура` |
| `laugh` | `pattern`, `enabled` | `(?:а?ха){2,}` |
| `stopwords` | `word` | `и, в, не, что…` |
| `meta` | `key`, `value` | `version_note`, `добавил имена` |

- **Формы имён:** сервер для `base` и каждого `variant` генерирует падежные формы через pymorphy3 (+ ручные `variants` для того, что морфология не знает), результат — регулярка-альтернация для браузера.
- Пользователь перед разбором может добавить свои имена/прозвища (до 20) — они проходят ту же генерацию форм.
- Нормализация текста перед матчингом: нижний регистр, `ё→е`, латинские двойники (`x→х`, `y→у`, `e→е`, `a→а`, `o→о`, `p→р`, `c→с`), сжатие повторов букв > 2 (`бляяя → бляя`) — делать в обоих вариантах.

### Синхронизация
- Worker раз в 6 часов и по кнопке в админке читает таблицу (Sheets API, сервисный аккаунт), валидирует: компилируются ли регулярки, нет ли дублей id, не слишком ли общий паттерн (тест на списке «безобидных» слов из `dictionaries/seed/safe_words.txt` — если паттерн мата цепляет > 0 безобидных слов, версия помечается невалидной).
- Валидная версия сохраняется в `dictionary_versions` и становится активной; невалидная — нет, админу уведомление с ошибками.
- Версия словаря пишется в каждый разбор (`dict_versions`) — отчёт воспроизводим.
- **Резерв:** `dictionaries/seed/*.csv` в репо — стартовая версия и для тестов. Если Google недоступен — работает последняя валидная версия из БД.

## Журналы и статистика (`ops_log`)
Зеркало для удобного просмотра автором; источник истины — PostgreSQL.

| Лист | Строка = | Колонки |
|---|---|---|
| `visits` | заход (сессия, не каждый хит) | дата-время, user_ref (или `anon`), источник (site/bot/miniapp), utm_source, utm_campaign, устройство (mobile/desktop) |
| `orders` | движение денег/разборов | дата-время, user_ref, тип (payment/promo/admin_grant/refund), метод (yookassa/stars/promo/admin), продукт, разборов, сумма ₽, сумма ⭐, промокод (маска), статус |
| `runs` | разбор | дата-время, user_ref, источник (tg/tt), тип чата, сводки (через запятую), списание (paid/free_rerun/admin), статус, время, размер пакета |
| `daily` | день | формулы `COUNTIFS/SUMIFS` по листам выше: пользователи, разборы, выручка, конверсия |
| `errors` | ошибка | дата-время, сервис, error_code, request_id, количество за час |

- Запись через `sheets_outbox`: worker раз в минуту отправляет пачку `values.append` (≤ 500 строк). Квоты Sheets API: ~60 запросов/мин на пользователя проекта — пачки с запасом укладываются. Повторы с экспоненциальной задержкой.
- **Почему user_ref, а не email:** 152-ФЗ требует хранить ПД россиян в БД в РФ; таблица Google — за рубежом. По `user_ref` автор находит пользователя в админке.

## Резервные копии
Бэкапы PostgreSQL содержат ПД → **не на Google Диск**, а в S3-хранилище в РФ (Timeweb/Selectel/Yandex Object Storage), шифрование `age`. На Google Диск — только код/дизайн/словари/документы.
