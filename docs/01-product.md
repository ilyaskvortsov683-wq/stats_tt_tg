# 01. Продукт: функции, сводки, тарифы

## 1. Пользовательские сценарии

1. **Telegram-личка.** Выгрузил чат в Telegram Desktop → открыл сайт → вошёл через Google → перетащил `result.json` → сразу видит бесплатно: сколько всего сообщений и сколько у каждого → ставит галочки на нужных сводках → тратит 1 разбор → получает отчёт, скачивает HTML/PDF/PNG.
2. **Telegram-беседа.** То же, плюс сводка «Жизнь беседы» (названия, добавления участников, пересылки).
3. **TikTok впервые.** Нажал «Как выгрузить?» → гайд → запросил выгрузку в приложении TikTok → в боте включил напоминание → через 1–2 дня бот напомнил → загрузил JSON → бесплатно видит число просмотров и счётчики сообщений по чатам → платно: экранное время, сессии, ритм, разбор одного выбранного чата и т.д.
4. **TikTok повторно через полгода.** Загрузил новую выгрузку → сервис склеил её с сохранённой историей → статистика уже за год.
5. **TikTok, несколько старых файлов.** Отправил боту одним сообщением (альбомом) 2–10 файлов `user_data_tiktok.json` → бот склеил → сохранил историю.
6. **Промокод.** Ввёл код → получил разборы (или скидку).
7. **Админ (автор).** Всё бесплатно; админка со статистикой, промокодами, пользователями, логами.

## 2. Сводки (галочки до анализа)

Перед запуском пользователь видит список сводок выбранного источника. Бесплатные отмечены и считаются сразу; платные помечены замком. Цена разбора **не зависит** от числа галочек — это фильтр содержимого отчёта, а не прайс. Последний выбор запоминается.

### Telegram

| ID | Сводка | Тариф | Только для |
|---|---|---|---|
| `tg.overview` | **Общее**: всего сообщений, у каждого участника (число и доля), период переписки | бесплатно | — |
| `tg.rhythm` | **Ритм**: по дням (с окраской по дням недели), неделям, месяцам, накопительно; топ-10 дней; последние 14 дней | разбор | — |
| `tg.clock` | **Часы и дни**: по часам суток, по дням недели, тепловая карта «час × день недели» | разбор | — |
| `tg.dialog` | **Диалог**: кто пишет первым после паузы, медианная скорость ответа, самый долгий перерыв, самый «жаркий» день, серии дней подряд | разбор | личка* |
| `tg.media` | **Медиа**: голосовые (число, минуты), кружки (число, минуты), фото/видео/стикеры/GIF, пересланные и их источники | разбор | — |
| `tg.words` | **Слова**: топ слов (со стоп-словами), свои слова для подсчёта, слова по маске | разбор | — |
| `tg.laugh_swear` | **Смех и мат**: «ахах»-индекс, мат по участникам и по времени | разбор | — |
| `tg.names` | **Имена**: упоминания имён во всех формах (склонения и уменьшительные) | разбор | — |
| `tg.reactions` | **Реакции, эмодзи и стикеры**: какие реакции, кто кому ставит, топ эмодзи, топ стикеров | разбор | — |
| `tg.group_life` | **Жизнь беседы**: история названий и сколько жило каждое, добавление участников на графике активности, вход/выход | разбор | беседа |

\* в беседе «Диалог» считается упрощённо: кто «запускает» беседу после паузы.

### TikTok

| ID | Сводка | Тариф |
|---|---|---|
| `tt.views_total` | **Просмотры — итог**: сколько видео просмотрено, за какой период, сколько выгрузок склеено | бесплатно |
| `tt.chats_counts` | **Чаты — счётчики**: по каждому чату число сообщений по отправителям: текстовые, присланные тиктоки, реакции/стикеры (если есть в экспорте) | бесплатно |
| `tt.views_rhythm` | **Ритм просмотров**: по дням, неделям, месяцам; часы суток; дни недели; тепловая карта | разбор |
| `tt.sessions` | **Сессии и экранное время**: сессии (разрыв > 5 мин), длительность, топ «залипаний», экранное время по дням с разбиением через полночь | разбор |
| `tt.activity` | **Активность**: лайки и избранное по месяцам, коллекции, входы по дням/неделям/часам | разбор |
| `tt.chat_deep` | **Разбор одного чата** (выбирается из списка): динамика, кто кому сколько тиктоков скинул, по годам, по дням, просмотрщик «громких» дней | разбор |
| `tt.emoji` | **Эмодзи и реакции** в чатах | разбор |
| `tt.content` | **Содержание просмотренного** (бета): топ авторов, хэштеги и их динамика, доля удалённых видео | разбор |

Склейка истории просмотров — не сводка, а базовая функция, работает всегда (при согласии на хранение).

> Матрица бесплатно/платно хранится в конфиге `config/tiers.yaml`, а не в коде, — автор сможет перекинуть сводку между тарифами без изменения логики (но платная логика всё равно физически на сервере).

## 3. Тариф и единица оплаты

- **Стартовый пакет:** 200 ₽ → **5 разборов**. Разборы общие для обеих вкладок (TikTok и Telegram).
  - Пример: 1 разбор TikTok (история просмотров + 1 чат) + 4 разбора Telegram (4 разных чата).
- В боте тот же пакет за Telegram Stars (цена в звёздах — в конфиге, ориентир ~150 ⭐, уточнить).
- **Повторный разбор того же чата** (тот же отпечаток) в течение 30 дней — бесплатно (свежий экспорт обновляет отчёт). Срок — в конфиге.
- **Разбор списывается только при успешном построении отчёта** (сначала резерв, при ошибке резерв снимается).
- **Промокоды:** дают N разборов или скидку; персональные (для одного пользователя) или общие (каждый может применить один раз); генерируются в админке.
- **Админ:** всё бесплатно, разборы не списываются, но логируются с пометкой `admin`.
- Позже: пакеты 1/5/15 разборов, «годовой» тариф для TikTok-склейки — гипотезы, проверять.

## 4. Экспорт результата

- **HTML** — самодостаточный файл, адаптивный под телефон, с переключателем темы.
- **PDF** — для печати и пересылки (A4, светлая тема по умолчанию, выбор темы).
- **PNG** — карточки для сторис (1080×1920) и полный отчёт длинной картинкой.
- На каждой карточке ненавязчивый водяной знак со ссылкой на сервис.

## 5. Гайды экспорта

На каждой вкладке кнопка **«Как выгрузить данные?»** → пошаговый гайд со скриншотами (тексты — `docs/guides/`). Гайд доступен без входа, а также в боте командой `/guide`.

## 6. Напоминания (бот)

- «Я запросил выгрузку TikTok» → напоминание через 24 ч (и повтор через 48 ч), по желанию.
- «Пора обновить историю» — раз в ~5 месяцев, чтобы старые просмотры не выпали из 6-месячного окна TikTok.
- Всё отключается одной кнопкой; тихие часы по часовому поясу.

## 7. Чего нет в первой версии

- Тональность, ML, анализ кадров видео.
- WhatsApp/VK/Instagram (кандидаты на будущее).
- Совместные отчёты на двоих с разных аккаунтов.
