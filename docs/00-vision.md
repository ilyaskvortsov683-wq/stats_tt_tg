# 00. Видение проекта

## Что это

Сервис, который превращает экспорт переписки или данных аккаунта в красивый статистический разбор.

- **Источники:** Telegram (`result.json` из Telegram Desktop) и TikTok (выгрузка «Download your data» в JSON).
- **Каналы:** веб-приложение (основное, вход через Google) и Telegram-бот (второй вход, напоминания, оплата звёздами).
- **Модель:** бесплатные базовые счётчики → платные подробные разборы пакетом «5 разборов за 200 ₽».
- **Цель автора:** пассивный доход; сервис работает автономно, автор только надзирает через админку, логи и Google-таблицу.

## Принципы

1. **Тексты переписок не покидают устройство** (на сайте). Браузер сам считает бесплатную часть и собирает обезличенный пакет агрегатов для платной. Исключение — загрузка файла через бота: файл обрабатывается на сервере в памяти и сразу удаляется (пользователь предупреждается).
2. **Платная часть защищена сервером.** Код платных метрик и рендер отчёта — только на сервере. Флажок в JS ничего не открывает.
3. **Пользователь сам выбирает сводки** галочками до запуска анализа. Отчёт содержит только выбранное.
4. **История просмотров TikTok копится у нас** (по согласию), потому что TikTok отдаёт только последние ~6 месяцев, а пользователи старые выгрузки не хранят. Каждая новая выгрузка склеивается с сохранённой.
5. **Без ML.** Статистика, регулярки, словари. Словари мата и имён редактируются автором в Google-таблице на Google Диске без деплоя.
6. **Красиво, а не «нейроночно».** Собственная дизайн-система: светлая, тёмная и несколько авторских палитр; типографика с характером; аккуратные графики.
7. **Подробные логи** всего, кроме содержимого переписок.
8. **Всё для админа бесплатно.**

## Глоссарий

| Термин | Значение |
|---|---|
| **Разбор** | Единица оплаты: один запуск платного анализа. Telegram: 1 разбор = 1 чат (личка или беседа). TikTok: 1 разбор = история просмотров + активность + 1 выбранный личный чат. Название — рабочее, см. OPEN-QUESTIONS. |
| **Пакет «5 разборов»** | Стартовый продукт: 200 ₽ → 5 разборов на балансе, тратятся в любой вкладке. |
| **Сводка** | Блок отчёта (например «Часы и дни», «Мат и смех»). Выбирается галочкой. |
| **Пакет агрегатов** | Обезличенный JSON со счётчиками, который браузер отправляет на сервер для платного разбора. Без текстов сообщений. |
| **Отпечаток чата** | `sha256(chat_id_из_экспорта + user_id)`. Повторный разбор того же чата в течение 30 дней бесплатен. |
| **Склейка** | Объединение нескольких выгрузок TikTok в одну историю с дедупликацией по паре (дата, ссылка). |
| **Словари** | Мат (корни/шаблоны), имена (базовое имя → формы), стоп-слова, смех. Живут в Google-таблице. |
| **Журнал (ledger)** | Неизменяемая таблица движений разборов: покупка, промокод, списание, возврат. Баланс = сумма. |

## Ключевые решения (кратко)

| Вопрос | Решение | Где подробно |
|---|---|---|
| Вход | Google OAuth; Telegram привязывается к аккаунту | 08 |
| Хостинг | VPS в РФ (Docker Compose). Vercel/Netlify — нет как основа, максимум прокси для запросов к TikTok | 19 |
| Хранение ПД | PostgreSQL в РФ; в Google Sheets — только псевдонимы | 16, 18 |
| Словари | Google-таблица на Диске автора, синхронизация сервисным аккаунтом + копия-заглушка в репо | 16 |
| Отчёт | Серверный HTML с SVG-графиками; PDF и PNG из того же HTML через Chromium | 13 |
| Содержание тиктоков | Только метаданные через публичный oEmbed (подпись, хэштеги, автор); сами видео не скачиваем | 17 |
| Оплата | Сайт — ЮKassa (или Robokassa); бот — Telegram Stars; единый баланс разборов | 09 |
