# 04. Каталог метрик

Каждая метрика имеет стабильный `id`, принадлежит сводке, имеет место вычисления (`client` — браузер, бесплатно; `server` — платно) и тип визуализации. Новые метрики добавляются через скилл `add-metric`.

Обозначения визуализаций: **KPI** — плитка с числом; **bar**, **line**, **area**, **heatmap**, **table**, **timeline**, **donut** (только для 2–3 долей).

## Telegram

### tg.overview — бесплатно, client
| id | Что | Виз. |
|---|---|---|
| `tg.msg_total` | Всего сообщений (без service) | KPI |
| `tg.msg_by_participant` | Сообщений у каждого, доля % | bar (гориз.) / donut для 2 |
| `tg.period` | Первая и последняя дата, число дней, активных дней | KPI |

### tg.rhythm — server
| id | Что | Виз. |
|---|---|---|
| `tg.daily` | По дням, окраска по дню недели | bar |
| `tg.daily_by_participant` | По дням на участника | line |
| `tg.weekly` | По неделям (от первой даты или от заданной) | bar |
| `tg.monthly` / `tg.monthly_cumulative` | По месяцам и накопительно, общее и на участника | line/area |
| `tg.top_days` | Топ-10 дней | table |
| `tg.last_14d` | Последние 14 дней по дням и участникам | table |
| `tg.avg_per_day` | Среднее и медиана в активный день | KPI |

### tg.clock — server
| `tg.by_hour` | По часам суток (0–23) | bar |
| `tg.by_weekday` | По дням недели | bar |
| `tg.hour_x_weekday` | Тепловая карта 7×24, общая и на участника | heatmap |
| `tg.night_owl` | Доля сообщений 00–05 у каждого | KPI |

### tg.dialog — server
| id | Определение |
|---|---|
| `tg.first_after_pause` | Сессия диалога начинается после паузы ≥ 6 ч (конфиг). Кто написал первым — счётчик и доля. |
| `tg.reply_time_median` | Для смены автора: `ts(B) − ts(последнего A)`, если < 12 ч. Медиана и p90 на участника. |
| `tg.longest_gap` | Самый долгий перерыв (даты, длительность). |
| `tg.hottest_day` | День с максимумом сообщений + его почасовой профиль. |
| `tg.streaks` | Самая длинная серия дней подряд с перепиской; текущая серия. |
| `tg.double_texting` | Средняя длина «очереди» сообщений одного автора подряд. |

### tg.media — server
| `tg.voice` | Голосовые: число, минуты, средняя длина — на участника; по датам | KPI, bar |
| `tg.video_notes` | Кружки: то же | KPI, bar |
| `tg.media_mix` | Фото / видео / стикеры / GIF / файлы на участника | bar (stacked) |
| `tg.forwards` | Пересланные на участника и топ-10 источников | bar, table |
| `tg.calls` | Звонки: число, суммарная длительность (если есть `phone_call`) | KPI |

### tg.words — server (счётчики считает client по словарю стоп-слов)
| `tg.top_words` | Топ-20 слов на участника и общий, без пересланных, без стоп-слов | bar |
| `tg.custom_words` | Счёт слов, которые ввёл пользователь (до 20 штук) | table |
| `tg.mask_words` | Слова по маске (начинается на X, содержит Y) — ввод пользователя | table |
| `tg.msg_length` | Средняя длина сообщения в словах на участника | KPI |

### tg.laugh_swear — server, словари: `laugh`, `swear`
| `tg.laugh` | Сообщения со смехом (регулярка `(?:а?ха){2,}|(?:хе){2,}|лол|ору` + словарь) на участника, по месяцам | bar, line |
| `tg.laugh_forms` | Топ «форм» смеха (ахахах, хахаха…) | table |
| `tg.swear` | Матерные слова на участника, на 1000 сообщений, по месяцам; топ корней (с маскировкой: «х*р») | bar, line |

### tg.names — server, словарь `names` + пользовательские имена
| `tg.names` | Упоминания имён во всех формах на участника и по месяцам | table, line |

### tg.reactions — server
| `tg.reactions_total` | Всего реакций, топ-10 эмодзи-реакций | bar |
| `tg.reactions_by_day` | Реакции по дням | bar |
| `tg.reactions_who_whom` | Кто чьи сообщения реагирует (оценка по `recent`) | heatmap/table |
| `tg.emoji_in_text` | Топ эмодзи в текстах на участника | bar |
| `tg.stickers` | Топ стикеров (по `sticker_emoji` + id файла) | table |

### tg.group_life — server, только беседы
| `tg.titles` | История названий: кто, когда, сколько жило; топ-10 по длительности | timeline, table |
| `tg.invites` | Добавления участников, отметки на графике активности | line + маркеры |
| `tg.members_flow` | Вступили/вышли по месяцам | bar |

## TikTok

### tt.views_total — бесплатно, client
| `tt.views_count` | Число просмотров (после склейки на сервере — уточняется) | KPI |
| `tt.views_period` | Период, число склеенных выгрузок | KPI |

### tt.chats_counts — бесплатно, client
| `tt.chat_counts` | По каждому чату: сообщений у каждого, из них текстовых, присланных тиктоков, реакций/стикеров (если есть) | table |

### tt.views_rhythm — server
| `tt.views_daily` / `weekly` / `monthly` | Просмотры по периодам | bar |
| `tt.views_by_hour`, `tt.views_by_weekday`, `tt.views_hour_x_weekday` | Профили и тепловая карта | bar, heatmap |

### tt.sessions — server
| `tt.sessions` | Сессия: просмотры с разрывом ≤ 5 мин (конфиг). Число, медиана длительности | KPI |
| `tt.screen_time_total` | Сумма длительностей сессий + оценка последнего видео сессии (медианный интервал) | KPI |
| `tt.screen_time_daily` | Экранное время по дням с разбиением сессий через полночь; подписи по понедельникам | bar |
| `tt.top_sessions` | Топ-3 (и таблица топ-20) самых длинных «залипаний» | table |
| `tt.screen_by_hour` | Экранное время по часам | bar |

### tt.activity — server
| `tt.likes_monthly`, `tt.favorites_monthly`, `tt.collections` | По месяцам | bar |
| `tt.logins` | Входы по дням, неделям, часам | bar, heatmap |

### tt.chat_deep — server, 1 чат
| `tt.chat_dynamics` | Сообщения по дням/месяцам на участника | line |
| `tt.shares_who_whom` | Кто кому сколько тиктоков скинул, по годам и по дням | bar, line |
| `tt.loud_days` | Дни с > N текстовых сообщений — счётчики (без текстов) | table |

### tt.emoji — server
| `tt.emoji_in_chats` | Топ эмодзи по чатам и участникам | bar |

### tt.content — server, бета (docs/17)
| `tt.top_authors` | Топ-20 авторов просмотренного | table |
| `tt.hashtags` | Топ хэштегов, динамика по месяцам | bar, line |
| `tt.deleted_share` | Доля видео, которые уже недоступны | KPI |

## Общие правила
- Неделя начинается с понедельника; дни недели — по-русски, сокращения «пн…вс».
- Пустые сводки (нет данных) не рисуются, вместо них строка «В экспорте нет данных для этой сводки».
- У каждого графика: заголовок-вывод («Вечером вы пишете в 3 раза чаще»), а не «График 1».
- Все пороги (пауза диалога, разрыв сессии) — в `config/metrics.yaml`.
