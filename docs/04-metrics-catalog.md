# 04. Каталог метрик

Где считается: **client** — в браузере (бесплатно, `packages/parsers/src/free.ts`); **server** — модель отчёта (`apps/api/app/metrics/report_model.py`), агрегация за выбранный период — в отчёте (`app/report/assets/report.js`). Пороги — `config/metrics.yaml`. Новая метрика — скилл `add-metric`.

**Период.** Любая сводка в отчёте пересчитывается за выбранный период (общий в шапке или свой у сводки). Масштаб графиков по времени выбирается сам: ≤ 62 дней — по дням, ≤ 400 — по неделям, дальше — по месяцам. Исключение: топ слов считается по целым месяцам, попавшим в период.

## Telegram

### tg.overview — бесплатно (client + в отчёте)
| Метрика | Что |
|---|---|
| Всего сообщений | без служебных |
| По участникам | число и доля |
| Период | первая/последняя дата, дней, активных дней, сообщений в активный день |

### tg.rhythm
По дням (выходные — акцентом), неделям, месяцам; по участникам (стек); накопительно; топ-10 дней; последние 14 дней периода по участникам; среднее и медиана в активный день.

### tg.clock
По часам суток; по дням недели; тепловая карта «день недели × час»; «ночные совы» — доля сообщений 00–05 у каждого (для чатов ≤ 4 участников).

### tg.dialog
| Метрика | Определение |
|---|---|
| Кто начинает разговор | первое сообщение после паузы ≥ `pause_hours` (6 ч) |
| Скорость ответа | при смене автора: время с предыдущего сообщения, если ≤ `reply_max_hours` (12 ч); гистограмма по дням с корзинами 0–10 с … 6–12 ч → медиана за любой период (оценка внутри корзины) |
| Самые долгие перерывы | топ-50 интервалов между сообщениями, в отчёте — топ-5 внутри периода |
| Серии | самая длинная серия дней подряд с перепиской; серия в конце периода |
| «Жаркий» день | день с максимумом сообщений |

### tg.moments — монологи и разговоры
| Метрика | Определение |
|---|---|
| Монолог | ≥ 2 сообщений одного автора подряд, перерывы ≤ `monologue_gap_min` (30 мин). Топ по числу сообщений и по числу слов |
| Разговор | непрерывная переписка, перерывы ≤ `dialog_gap_min` (30 мин), ≥ 2 участника и ≥ 4 сообщений. Топ по длительности, сообщениям, словам |
| Хранение | топ-200 по каждому критерию (объединение) — чтобы для любого периода найти лучшие |
| Текст | кнопка «Текст» → тексты из файла в браузере (не с сервера), сохранение в файл или «избранное» |

### tg.media
Голосовые и кружки (число, суммарная длительность), фото, видео, стикеры, GIF, файлы, ссылки, опросы — по участникам; пересланные и топ-10 источников; звонки (число, длительность); голосовые по периоду.

### tg.words
Топ слов каждого (≥ 3 букв, без стоп-слов и пересланных; в пакете — топ-100 на участника за месяц); свои слова и маски (`*` — любые буквы, `?` — одна) по участникам; какие слова подошли под маску.

### tg.laugh_swear
Сообщения со смехом (регулярки из словаря `laugh`) — на 100 сообщений; формы смеха; мат (точные формы + корни из словаря, с исключениями) — на 1000 сообщений, по периодам, частые слова с маской.

### tg.names
Упоминания имён: формы генерирует сервер (pymorphy3 + окончания + уменьшительные из словаря), неоднозначные слова («Вера», «Роман», «=кости») исключены; плюс свои имена пользователя.

### tg.reactions
Всего реакций, топ эмодзи-реакций, кто собирает реакции, «кто кому» (оценка по `recent`), эмодзи в тексте, любимые стикеры.

### tg.group_life (только беседы)
Названия: кто, когда, сколько прожило, топ по длительности; новые участники по периодам.

## TikTok

### tt.views_total — бесплатно
Просмотров, период, в среднем в день (по активным дням в отчёте).

### tt.chats_counts — бесплатно (только в приложении)
По каждому чату и отправителю: текст, присланные тиктоки, прочее.

### tt.views_rhythm
Просмотры по периодам (выходные — акцентом), по часам, по дням недели, тепловая карта.

### tt.sessions
| Метрика | Определение |
|---|---|
| Сессия | просмотры с перерывами ≤ `tt_session_gap_min` (**10 мин**) |
| Длительность | последний − первый просмотр + оценка последнего видео (медиана интервалов внутри сессий, 5–60 с) |
| Экранное время | сумма сессий, разбиение через полночь и по часам |
| Показано | экранное время, в среднем в день, число сессий, медиана, самое долгое «залипание», по часам суток, топ-20 |

### tt.activity
Лайки, избранное, входы — по периодам; входы по часам.

### tt.chat_deep
Кто кому сколько тиктоков прислал (стек по периодам), таблица: тиктоки / текст / всего.

### tt.emoji
Эмодзи в выбранном чате по участникам.

### tt.content (бета, фаза 11)
Топ авторов, хэштеги, доля недоступных видео (docs/17).

## Общие правила
- Неделя с понедельника; даты и дни недели по-русски.
- Пустая сводка — фраза «В выбранном периоде нет данных…», без пустых графиков.
- Заголовок графика — вывод с числом, а не «График 1».
