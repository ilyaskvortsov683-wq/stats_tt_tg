# Privacy guard

Первой строкой ответа: `🔧 Скилл: privacy-guard — <что проверяю>`.

Источники правды: `docs/18-security-privacy-legal.md`, `docs/14-logging.md`, `docs/05-aggregate-packet.md`.

## Проверь в своём диффе
1. **Тексты сообщений** не попадают: в пакет агрегатов, логи (`structlog`, `console`), события `events`, Sheets, ошибки/стектрейсы, URL-параметры, аналитику клиента.
2. **ПД** (email, tg_id, IP, имена участников чатов, названия чатов) не попадают в логи и Sheets — только `user_ref`, хэши, корзины размеров.
3. Файлы из бота удаляются после обработки (и с диска локального bot-api).
4. Новые поля пакета — только числа, даты, эмодзи, id словарей. Топ-слова — только после стоп-слов и длиной ≥ 3.
5. TikTok-история хранится зашифрованной; IP и устройства из Login History на сервер не уходят.
6. В `samples/` ничего не добавлено в git (проверь `git status`).
7. Тест с «ядовитыми» строками (`POISON_TEXT_42`, email, телефон) расширен на новый код и проходит.

Если что-то из этого нарушено — исправь до коммита и опиши в ответе, что нашёл.
