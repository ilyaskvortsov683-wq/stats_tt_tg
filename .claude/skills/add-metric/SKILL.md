# Добавление метрики

Первой строкой ответа: `🔧 Скилл: add-metric — <какая метрика>`.

## Чек-лист (все пункты в одном коммите)
1. **Каталог.** Добавь строку в `docs/04-metrics-catalog.md`: `id`, сводка, тариф, где считается, визуализация, точное определение (пороги — в `config/metrics.yaml`).
2. **Тариф.** Если новая сводка — добавь в `config/tiers.yaml` и в таблицу `docs/01-product.md`.
3. **Данные.**
   - Хватает ли полей пакета (`docs/05`)? Если нет — расширь `packages/schema` (новая минорная версия, обратная совместимость), обнови оба сборщика (TS `packages/parsers`, Python `apps/api/app/parsers`).
   - **Никаких текстов** в пакете — только счётчики/даты (загрузи `privacy-guard`, если трогаешь пакет).
4. **Расчёт.**
   - Бесплатная → `packages/parsers/src/metrics/free/<id>.ts`.
   - Платная → `apps/api/app/metrics/paid/<section>.py`, чистая функция `packet → dict`.
5. **Фикстура.** Дополни генератор `fixtures/generate.py` так, чтобы метрика имела известное ожидаемое значение; обнови `*.expected.json`.
6. **Тесты.** Golden-тест значения; для пакета — тест паритета TS/Python.
7. **Отчёт.** Шаблон `report/sections/<section>.html`: заголовок-вывод, график по правилам `design-system` + `dataviz`, мобильная раскладка, пустое состояние.
8. **UI выбора сводок.** Описание сводки (одна строка) и иконка.
9. **Пример.** Если меняется содержание отчёта — обнови `docs/report-sample.md`.
10. Прогони все тесты и скриншот-тесты отчёта.
