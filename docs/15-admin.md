# 15. Админка

Роуты `/admin/*` веб-приложения, доступ — `role=admin` (проверка на сервере в каждом `/admin` API). Все действия — в `admin_audit`.

## Разделы

### Обзор (дашборд)
- KPI за период (сегодня / 7 / 30 дней / свой): новые пользователи, активные, загрузки файлов, бесплатные анализы, разборы (платные / повторы / админ), выручка ₽ и ⭐, конверсия «загрузил → купил», средний чек, промокоды.
- Ряды по дням: пользователи, разборы по источникам (TG/TT), выручка.
- Воронка: лендинг → вход → загрузка → бесплатный результат → выбор сводок → покупка → разбор.
- Популярность сводок (какие галочки ставят).
- Здоровье (docs/14).

### Пользователи
Поиск по email / user_ref; карточка: идентичности, баланс, журнал, разборы, платежи, промокоды, последние события. Действия: начислить разборы (с причиной), вернуть платёж, сбросить сессии, удалить аккаунт.

### Промокоды
- Таблица: код, тип, значение, охват, использовано/лимит, срок, статус, заметка.
- Форма генерации: тип (`runs`/`discount_percent`/`fixed_price`), значение, охват (`personal` — выбор пользователя по email; `global`), лимит, срок, свой код или автоген, количество (массово), заметка. Экспорт CSV.
- Отключить/продлить; список применений.

### Разборы и ошибки
Список разборов с фильтрами (статус, источник, сводки, длительность), карточка ошибки (`error_code`, `request_id`, шаги, тайминги — без данных пользователя). Кнопка «вернуть разбор».

### Журнал событий
Фильтры по уровню, типу, user_ref, run_id, request_id, периоду. Живой режим (SSE).

### Словари
Текущие версии, дата синхронизации, ошибки валидации, кнопка «Синхронизировать сейчас», откат к предыдущей версии.

### Интеграции
Статус Google Sheets (очередь outbox, последняя отправка), Google Drive, ЮKassa (последний webhook), бот (webhook info), oEmbed-прокси.

### Настройки
Цены и пакеты (read-only из конфига, изменения через коммит), тумблеры: `FREE_REQUIRES_LOGIN`, приём оплат, режим обслуживания, бета `tt.content`.

## Админ как пользователь
В обычном интерфейсе у админа бейдж «Админ», все сводки без замков, баланс «∞».
