# 01. Продукт: функции, сводки, тарифы

## 1. Сценарии

1. **Telegram-личка.** Выгрузил чат в Telegram Desktop → вошёл через Google → перетащил `result.json` → выбрал город (время в отчёте по нему) и «кто из них вы» → сразу видит бесплатно: всего сообщений и у каждого → ставит галочки → тратит 1 разбор → отчёт, в котором можно выбрать любой период.
2. **Telegram-беседа.** То же + «Жизнь беседы» (названия, новые участники).
3. **TikTok впервые.** «Как выгрузить?» → гайд → запросил выгрузку → в боте включил напоминание → через 1–2 дня бот напомнил → загрузил JSON → бесплатно: число просмотров и счётчики сообщений по чатам → платно: экранное время, сессии, ритм, активность, разбор одного чата.
4. **TikTok через полгода.** Новая выгрузка склеивается с сохранённой историей.
5. **TikTok, несколько старых файлов.** Загрузил разом на сайте или (фаза 9) переслал боту одним сообщением.
6. **Моменты.** В отчёте нажал «Текст» у самого длинного монолога → увидел сообщения (из файла в браузере) → сохранил в файл или «в избранное».
7. **Промокод.** Ввёл код → получил разборы или скидку.
8. **Админ.** Всё бесплатно; админка со статистикой, промокодами, пользователями, журналом.

## 2. Сводки (галочки до анализа)

Бесплатные посчитаны сразу и всегда в отчёте; платные — с пометкой «разбор». Цена разбора **не зависит** от числа галочек. Последний выбор запоминается. В готовом отчёте у каждой сводки свой выбор периода (по умолчанию — общий период отчёта = весь экспорт).

### Telegram
| ID | Сводка | Тариф | Только |
|---|---|---|---|
| `tg.overview` | **Общее**: всего сообщений, у каждого (число и доля), период, активные дни | бесплатно | — |
| `tg.rhythm` | **Ритм**: по дням (выходные выделены) / неделям / месяцам — масштаб по длине периода, накопительно, топ-10 дней, последние 14 дней | разбор | — |
| `tg.clock` | **Часы и дни**: по часам, по дням недели, тепловая карта, «ночные совы» | разбор | — |
| `tg.dialog` | **Диалог**: кто начинает разговор после паузы ≥ 6 ч, медиана скорости ответа, самые долгие перерывы, серии дней подряд, самый «жаркий» день | разбор | — |
| `tg.moments` | **Монологи и диалоги**: самый длинный монолог по сообщениям и по словам; самый долгий разговор по времени, по сообщениям, по словам; кнопка «Текст» и сохранение момента | разбор | — |
| `tg.media` | **Медиа**: голосовые и кружки (число, минуты), стикеры, фото, видео, GIF, файлы, ссылки, пересланное и источники, звонки | разбор | — |
| `tg.words` | **Слова**: топ слов каждого; свои слова и маски (`росси*`, `д*а*`) | разбор | — |
| `tg.laugh_swear` | **Смех и мат**: доля сообщений со смехом, формы смеха, мат на 1000 сообщений, по времени, частые слова (с маской) | разбор | — |
| `tg.names` | **Имена**: упоминания во всех формах + свои имена и прозвища | разбор | — |
| `tg.reactions` | **Реакции, эмодзи, стикеры**: какие реакции, кто кому, эмодзи в тексте, любимые стикеры | разбор | — |
| `tg.group_life` | **Жизнь беседы**: история названий и сколько жило каждое, новые участники | разбор | беседа |

### TikTok
| ID | Сводка | Тариф |
|---|---|---|
| `tt.views_total` | **Просмотры — итог**: сколько, за какой период, сколько выгрузок склеено | бесплатно |
| `tt.chats_counts` | **Чаты — счётчики**: по каждому чату сообщения отправителей — текст / тиктоки / прочее (реакции и стикеры — если найдутся в экспорте) | бесплатно (только в приложении) |

| `tt.emoji` | **Эмодзи** в выбранном чате | разбор |
| `tt.content` | **Содержание просмотренного** (бета): авторы, хэштеги через oEmbed | разбор, скоро |

Матрица бесплатно/платно — `config/tiers.yaml`.

## 3. Тариф

- **5 разборов — 200 ₽** (ЮKassa) или **150 ⭐** в боте. Разборы общие для сайта и бота, для TikTok и Telegram.
- Повторный разбор того же чата в течение **30 дней** — бесплатно.
- Разбор списывается только при успешном отчёте; при ошибке возвращается автоматически.
- **Промокоды:** N разборов, скидка % или фиксированная цена; для одного пользователя или для всех (каждый применяет один раз), с лимитом и сроком; создаются в админке.
- **Админ:** всё бесплатно, разборы помечаются `admin`.
- Позже: пакеты 1/5/15, «годовой» TikTok — гипотезы.

## 4. Экспорт результата
- **HTML** — самодостаточный файл (работает офлайн), адаптивный, с переключателем темы и выбором периода. ✅ v0.1
- **PDF** и **PNG** (длинный и карточки для сторис 1080×1920) — фаза 7.
- **Моменты** (монологи/разговоры с текстом) — сохраняются в HTML-файл или «в избранное» на устройстве. ✅ v0.1

## 5. Гайды экспорта
Кнопка «Как выгрузить?» на каждой вкладке и на лендинге → пошаговый гайд (`docs/guides/`), в боте `/guide`.

## 6. Напоминания (бот)
«Я запросил выгрузку» → через 24 ч / 48 ч / завтра в 19:00 (по поясу пользователя) → «Ещё не готово — завтра». Позже: «пора обновить историю» раз в ~5 месяцев.

## 7. Не в v1
Тональность и ML, анализ кадров видео, английский интерфейс и международные платежи, WhatsApp/VK.
