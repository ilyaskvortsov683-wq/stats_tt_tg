# Как работать над проектом с Claude

## Процесс
1. Вы пишете в сессии: «Фаза N» (промпты — в ROADMAP).
2. Claude читает CLAUDE.md и документы фазы, пишет код, сам запускает тесты и линтеры (вы только подтверждаете действия).
3. **В конце ответа — один коммит и пуш** в рабочую ветку. Промежуточных коммитов нет.
4. Деплой — только по вашей явной команде.
5. Если по ходу меняется решение — Claude обновляет соответствующий документ в том же коммите.

Рекомендуемый уровень effort — указан у каждой фазы в ROADMAP: **high** для дизайна, денег, парсеров, бота и прода; **medium** для остального.

## Скиллы: как это устроено
- **Использует ли Claude скиллы сам?** Да. Скиллы, доступные в сессии (подключённые к вашему аккаунту и лежащие в репозитории в `.claude/skills/`), Claude загружает сам, когда задача подходит под описание скилла. Называть скилл не обязательно, но можно («используй dataviz») — тогда он загрузится наверняка.
- **Может ли Claude добавить скилл вам?** В аккаунт — нет, установить скилл за вас Claude не может (может показать карточку-предложение, если в каталоге есть подходящий). Зато Claude может **написать проектные скиллы прямо в репозиторий** — они подхватываются в каждой сессии с этим репо. Уже сделано:
  - `design-system` — правила дизайна этого проекта;
  - `add-metric` — как добавлять метрику по всей цепочке;
  - `privacy-guard` — проверка, что тексты и ПД никуда не утекают.
- В этой среде из готовых для дизайна есть `dataviz` (графики, палитры, проверка контраста) и `artifact-design`.
- **Видно ли, что скилл включился?** Вызов скилла и так отображается в ленте сессии отдельным шагом (Skill). Дополнительно в CLAUDE.md записано правило: при включении скилла Claude первой строкой пишет `🔧 Скилл: <имя> — <зачем>`.

## Заполнение контекста в реальном времени
- В терминальной версии Claude Code это настраивается строкой статуса (`/statusline`) — она может показывать процент заполненного контекста под полем ввода.
- В любой версии можно в любой момент ввести `/context` — покажет разбивку заполнения.
- В десктопном/веб-приложении постоянный индикатор под полем ввода делается модом интерфейса (у Claude есть скилл для создания модов: полоса над полем ввода, статус-строка). Это отдельная небольшая задача — скажите «сделай индикатор контекста», и Claude сделает её отдельно от проекта.

## Образцы данных
Присылайте файлы как вложения или кладите в папку проекта на Google Диске `samples/`. Claude положит их в `samples/` репозитория — папка в `.gitignore` и никогда не коммитится.
