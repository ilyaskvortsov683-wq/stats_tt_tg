# Как выгрузить чат из Telegram

> Экспорт делается **только в Telegram Desktop** (компьютер: Windows, macOS, Linux). В мобильном приложении такой функции нет. Скачать: desktop.telegram.org.

## Шаг 1. Установите и откройте Telegram Desktop
Войдите в свой аккаунт (по QR-коду с телефона).
*Скриншот: окно входа по QR.*

## Шаг 2. Откройте нужный чат
Личный чат или беседу, которую хотите разобрать.

## Шаг 3. Меню чата → «Экспорт истории чата»
Нажмите ⋮ (три точки) в правом верхнем углу → **«Экспорт истории чата»**.
*Скриншот: меню чата с выделенным пунктом.*

## Шаг 4. Снимите галочки с медиа
Фото, видео, голосовые и т.д. для статистики **не нужны** — без них экспорт в сотни раз меньше и быстрее. Длительность голосовых и кружков всё равно сохранится.
*Скриншот: окно экспорта, галочки сняты.*

## Шаг 5. Формат — «Машиночитаемый JSON»
Внизу окна: **Формат → JSON**. Это обязательно: HTML-формат не подойдёт.
*Скриншот: выбор формата JSON.*

## Шаг 6. Период — «За всё время» и «Экспортировать»
Дождитесь окончания и нажмите «Показать мои данные».

## Шаг 7. Загрузите файл `result.json`
В открывшейся папке будет файл **result.json** — перетащите его на сайт или отправьте боту.

### Если хотите разобрать несколько чатов сразу
Настройки → Продвинутые настройки → **«Экспорт данных из Telegram»** → отметьте нужные типы чатов, формат JSON. Получится один большой `result.json` со всеми чатами — на сайте вы выберете нужный.

### Приватность
На сайте файл обрабатывается прямо в вашем браузере и никуда не отправляется. Через бота файл обрабатывается на сервере в памяти и удаляется сразу после подсчёта.
