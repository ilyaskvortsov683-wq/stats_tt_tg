# Дорожная карта

Фазы идут последовательно; внутри фазы задачи можно делать в одной сессии. Для каждой фазы: цель, задачи, критерии приёмки, документы, рекомендуемый уровень effort исполнителя и готовый промпт.

Общий промпт-префикс для любой фазы:
> Прочитай CLAUDE.md и docs/ROADMAP.md (фаза N), затем все документы из раздела «Документы» фазы. Сделай фазу целиком, проверь тестами и линтерами, обнови документы, если что-то изменилось. В конце — один коммит и пуш.

## Фаза 0. Подготовка и сверка форматов (автор + Claude, без кода продукта)
**Цель:** всё внешнее заведено, форматы подтверждены образцами.
- [ ] Автор присылает образцы: TG личка, TG беседа, TT выгрузка (2 разных даты) → `samples/` (не коммитится).
- [ ] Claude сверяет с docs/03, обновляет документ (ключи, синонимы разделов, есть ли реакции/стикеры в TT-чатах, часовой пояс TT, формат ссылок).
- [ ] Google Cloud проект, OAuth consent, сервисный аккаунт; папка на Drive, таблицы `dictionaries` и `ops_log` по шаблону docs/16 (Claude может создать таблицы через коннектор Google Drive).
- [ ] Бот в BotFather, домен, VPS (можно позже, к фазе 4).
- [ ] Ответы на OPEN-QUESTIONS (название, единица оплаты, налоговый режим).
**Готово, когда:** docs/03 помечен «сверено с образцами», таблицы созданы, секреты лежат у автора.
**Effort:** medium.

## Фаза 1. Каркас монорепо, CI, дизайн-токены
- [ ] pnpm workspaces + uv; структура из docs/02 §4; `.env.example`; docker compose для local (postgres, redis).
- [ ] `packages/design-tokens`: tokens.json со всеми палитрами docs/12 → генерация CSS; проверка контраста скриптом.
- [ ] `apps/web`: Vite + React + роутер, шрифты (самохостинг), ThemeSwitcher, базовые компоненты (Button, Checkbox-карточка, Tabs, Dropzone, Stepper, KPI, ChartFrame, Table, Toast, Dialog).
- [ ] Страница-витрина компонентов `/dev/ui` во всех палитрах (для визуальной проверки).
- [ ] Лендинг (каркас) и гайды экспорта из `docs/guides` (степпер, без скриншотов — заглушки).
- [ ] `apps/api`: FastAPI hello, `/healthz`, structlog + scrub-процессор + тест.
- [ ] CI: lint, typecheck, тесты.
**Готово:** CI зелёный; `/dev/ui` выглядит аккуратно в 6 палитрах × светлая/тёмная на 360 и 1280.
**Документы:** 02, 11, 12, 14, guides. **Effort:** high (дизайн-основа).

## Фаза 2. Парсеры и нормализованная модель (TS + Python)
- [ ] Генератор синтетических фикстур + `*.expected.json` (docs/20).
- [ ] `packages/parsers`: TG (одиночный чат, полный экспорт), TT (все разделы, синонимы ключей), нормализация текста; запуск в Web Worker с прогрессом; потоковый парсинг больших файлов.
- [ ] `apps/api/app/parsers`: то же на Python.
- [ ] Тест паритета нормализованной модели.
**Готово:** все фикстуры парсятся одинаково; 300 МБ — в бюджете docs/20.
**Документы:** 03, 20. **Effort:** high.

## Фаза 3. Бесплатная часть в браузере + выбор сводок
- [ ] Бесплатные метрики TG (`tg.overview`) и TT (`tt.views_total`, `tt.chats_counts`).
- [ ] Экраны /app/tg и /app/tt до шага «выбор сводок» включительно (галочки, поля своих слов/имён, запоминание выбора), «Кто из них вы?».
- [ ] Бесплатная PNG-карточка в браузере.
- [ ] `config/tiers.yaml` читается фронтом через API (пока статично).
**Готово:** пользователь без сервера видит бесплатную часть на любой фикстуре, интерфейс адаптивен.
**Документы:** 01, 04, 11, 12. **Effort:** medium.

**Документы:** 04, 05, 12, 13, report-sample. **Effort:** high. Можно разбить на 6a (пакет+метрики) и 6b (отчёт).
