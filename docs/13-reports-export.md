# 13. Отчёт и экспорт (HTML / PDF / PNG)

## Источник истины — серверный HTML
- Jinja2-шаблон `report/base.html` + частичные шаблоны на каждую сводку `report/sections/<section_id>.html`.
- Графики — SVG, сгенерированные Python-модулем `report/charts/` (bar, line, area, heatmap, timeline, donut, sparkline). Цвета — через CSS-переменные (`fill: var(--series-1)`), поэтому темы переключаются без перерисовки.
- CSS токенов и шрифты (subset, base64 WOFF2) встраиваются в файл → **один самодостаточный HTML**, открывается офлайн, весит ~300–800 КБ.
- Встроенный переключатель темы в отчёте (маленький JS ≤ 3 КБ; без JS отчёт полностью читаем).

## Структура отчёта
1. Обложка: название чата (или «Ваш TikTok»), период, 3–4 главных KPI, дата построения.
2. Оглавление (якоря) — только выбранные сводки.
3. Сводки в порядке каталога. Каждая: заголовок, 1–3 вывода текстом, графики, таблицы.
4. «Как считали»: определения (пауза диалога 6 ч, сессия 5 мин и т.п.), версии словарей, сноски (реакции — оценка).
5. Подвал: ссылка на сервис, водяной знак.

## Адаптивность
- Mobile-first: на ширине < 640px графики на всю ширину, горизонтальные бар-чарты вместо вертикальных с длинными подписями, тепловая карта 7×24 поворачивается (24 строки × 7 колонок).
- `viewBox` у SVG, без фиксированных размеров; таблицы — горизонтальный скролл внутри блока, не страницы.
- Проверка в CI: Playwright-скриншоты на 360/768/1280, тест «нет горизонтального скролла страницы».

## PDF
- Playwright → `page.pdf({format: 'A4', printBackground: true})`, отдельный `@media print`: разрывы перед сводками, без переключателя темы, графики не режутся (`break-inside: avoid`).
- Тема по выбору (по умолчанию «Бумага»). Номера страниц в колонтитуле.

## PNG
- **Длинный PNG** — `page.screenshot({fullPage: true})` при ширине 1080 (мобильная раскладка, читаемо на телефоне).
- **Карточки для сторис** — отдельные шаблоны `report/cards/*.html` 1080×1920 и 1080×1080, скриншот каждого.
- Бесплатная карточка «Всего сообщений» рисуется **в браузере** (canvas/SVG → PNG), без сервера.

## Очередь и кэш
- Экспорт — задача arq; результат кэшируется по `(run_id, format, theme)`.
- Лимит одновременных Chromium — 2 (RAM). Таймаут 60 с.
