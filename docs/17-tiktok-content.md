# 17. Можно ли анализировать содержание тиктоков

## Что есть в выгрузке
В истории просмотров только **дата** и **ссылка** на видео. Ни подписи, ни автора, ни хэштегов, ни звука.

## Варианты

| Способ | Что даёт | Оценка |
|---|---|---|
| **Публичный oEmbed** `https://www.tiktok.com/oembed?url=<ссылка на видео>` | подпись к видео (`title`, вместе с хэштегами), автор (`author_name`, `author_unique_id`), превью (`thumbnail_url`) | ✅ **берём** — официальный публичный эндпоинт для встраивания, без ключей |
| TikTok Research API | расширенные метаданные | ❌ только для аккредитованных исследователей, не для коммерческого сервиса |
| TikTok Display API / Login Kit | данные о собственных видео пользователя | ❌ не про просмотренное |
| Скачивание видео и анализ кадров/звука | содержание | ❌ нарушает правила TikTok, тяжело, это ML — вне рамок |
| Скрейпинг страниц | всё | ❌ правила, нестабильно, блокировки |

## План для сводки `tt.content` (бета, платно)
1. Из склеенной истории берём уникальные `video_id`.
2. **Общий кэш `tt_video_meta`** (видео повторяются между пользователями — популярное смотрят все; кэш не содержит ПД пользователя).
3. Для отсутствующих в кэше — выборка до 2 000 видео (стратифицированно по месяцам, чтобы динамика была честной) — запросы oEmbed с ограничением ~3–5 запросов/сек, повторы, пометка `unavailable` для удалённых/приватных.
4. Ссылки вида `tiktokv.com/share/video/<id>` нужно привести к `https://www.tiktok.com/@/video/<id>` — **проверить на практике**, какой формат oEmbed принимает (фаза 12, первый шаг — спайк на 50 ссылках).
5. Метрики: топ авторов (с долей от просмотренного), топ хэштегов, их динамика по месяцам, доля недоступных видео, «ваши авторы» (смотрели > N раз). Хэштеги — из подписи регуляркой `#[\w\d_]+`.
6. Подпись видео не выводится в отчёт целиком (чужой контент) — только хэштеги и авторы.

## Риски
- Доступность tiktok.com с VPS в РФ и лимиты oEmbed неизвестны. Если с российского IP не работает — маленький прокси-эндпоинт за рубежом (например, функция на Vercel), через который идут **только id видео** (не ПД). Это единственное место, где Vercel уместен.
- Время: 2 000 запросов при 4 rps ≈ 8–9 минут → сводка считается асинхронно, отчёт дорисовывается; пользователь получает уведомление.
- Если oEmbed закроют — сводка скрывается флагом, остальной продукт не страдает.
