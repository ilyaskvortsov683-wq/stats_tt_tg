# 18. Безопасность, приватность, право

> Не юридическая консультация. Перед запуском — проверить у юриста/бухгалтера.

## Какие данные где
| Данные | Где | Защита |
|---|---|---|
| Тексты переписок (сайт) | только браузер | не передаются |
| Файлы через бота | RAM сервера + временно диск локального bot-api | удаление сразу после разбора, cron-очистка |
| Пакет агрегатов | сервер, в задаче | удаляется после рендера (храним только отчёт) |
| Отчёты | диск/S3 в РФ | шифрование at-rest, 90 дней |
| TikTok-история (дата + id видео) | PostgreSQL, РФ | AES-GCM, ключ из секретов, по согласию, удаляется по кнопке |
| Email, имя, tg_id, платежи | PostgreSQL, РФ | доступ только api; бэкапы шифруются |
| Журналы в Google Sheets | Google | только `user_ref`, без ПД |
| Словари | Google Drive + репо | не ПД |

## 152-ФЗ
- **Локализация:** запись, систематизация, накопление и хранение ПД граждан РФ — в БД на территории РФ (ст. 18 ч. 5). Отсюда VPS в РФ.
- **Уведомление Роскомнадзора** об обработке ПД — до начала обработки.
- **Трансграничная передача** (Google — вход, Sheets): вход через Google — передача email Google инициирует сам пользователь; в Sheets ПД не передаём. Уведомление о трансграничной передаче — уточнить у юриста.
- **Политика обработки ПД** и **согласие** (чекбокс при первом входе): цели, состав, сроки, права, контакт.
- **Данные третьих лиц в чатах:** на сайте тексты не покидают устройство; через бота — обработка в памяти без хранения. Явно написать в политике и в боте.

## Оферта и продажи
- Публичная оферта: что такое разбор, когда он считается оказанным (построен отчёт), возвраты («отчёт не построился — вернём»), сроки хранения.
- Реквизиты ИП/самозанятого на сайте, чеки по 54-ФЗ (через ЮKassa/Робочеки или «Мой налог» для НПД).
- Режим налогообложения — OPEN-QUESTIONS.

## Безопасность приложения
- Сессии: httpOnly cookie, CSRF, rate limits (docs/06).
- CSP: `default-src 'self'`; отчёты отдаются с отдельным строгим CSP и `sandbox` в iframe.
- Пакет: строгая валидация, лимиты размера, gzip-бомбы (лимит распакованного размера 50 МБ).
- Загрузка в бота: проверка размера и типа, распаковка zip с лимитами (zip-slip, бомбы).
- Webhooks: ЮKassa — перезапрос платежа + IP allowlist; Telegram — секрет в пути и `X-Telegram-Bot-Api-Secret-Token`.
- Секреты: `.env` на сервере, GitHub Environments для деплоя. Ротация ключа шифрования истории — с версией ключа в записи.
- Зависимости: Dependabot, `pip-audit`, `pnpm audit` в CI.
- Админка: только роль из `ADMIN_EMAILS`, audit-лог, опционально второй фактор (TOTP) позже.

## Удаление данных
«Удалить аккаунт» → удаление отчётов, истории, сессий, идентичностей; платежи обезличиваются и хранятся по закону; запись в `events` без ПД остаётся.
