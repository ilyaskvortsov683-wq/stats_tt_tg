# Что нужно сделать автору (и что сделает Claude)

Всё, что требует вашего паспорта, денег или входа в ваши аккаунты, делаете вы — по шагам ниже, мышкой в браузере. Всё остальное (код, настройки, команды, проверка) делает Claude. Командная строка вам не нужна.

## 1. Сервер (Timeweb Cloud) — ~15 минут, ~600–1500 ₽/мес
1. Зарегистрируйтесь на timeweb.cloud, подтвердите телефон, пополните баланс (~1000 ₽).
2. «Облачные серверы» → «Создать»: Ubuntu 24.04, регион Москва или Санкт-Петербург, 2 vCPU / 4 ГБ RAM / 50 ГБ NVMe.
3. Доступ: по паролю (придёт на почту) — подойдёт для старта. Позже Claude сгенерирует SSH-ключ и пришлёт открытую часть, вы вставите её в панели («SSH-ключи»).
4. Пришлите Claude IP-адрес сервера (не пароль — пароль вставите сами в секреты GitHub, шаг 5).

## 2. Домен — ~10 минут, от 200 ₽/год
1. Купите домен (reg.ru, Timeweb или другой регистратор в РФ).
2. В DNS добавьте запись **A**: `@` → IP сервера. Сертификат HTTPS выпустится сам.

## 3. Google (вход и таблицы) — ~20 минут, бесплатно
1. console.cloud.google.com → создать проект `stats-tt-tg`.
2. «APIs & Services» → включить **Google Sheets API** и **Google Drive API**.
3. «OAuth consent screen» → External → название сервиса, ваш email, домен, ссылка на политику.
4. «Credentials» → «Create OAuth client ID» → Web application → Authorized redirect URI: `https://ВАШ-ДОМЕН/api/v1/auth/google/callback`. Скопируйте Client ID и Client Secret.
5. «Service accounts» → создать → «Keys» → «Add key» → JSON. Файл понадобится в шаге 5.
6. В папке «Приложения / Аналитика истории тг и тт» на Диске Claude создаст таблицы `dictionaries` и `ops_log` (через подключённый Google Диск) — вам останется нажать «Поделиться» и добавить email сервисного аккаунта (редактор для `ops_log`, читатель для `dictionaries`).

## 4. Telegram-бот — ~5 минут
1. В Telegram откройте @BotFather → `/newbot` → имя и username. Скопируйте токен.
2. `/setdomain` → выберите бота → ваш домен (нужно для кнопки «Войти через Telegram»).

## 5. ЮKassa — после того как сайт заработает (модерация смотрит на сайт)
1. yookassa.ru → подключение для самозанятых → по ИНН.
2. Включите автоматическую регистрацию доходов в «Мой налог».
3. В разделе «Интеграция → HTTP-уведомления» укажите `https://ВАШ-ДОМЕН/api/v1/webhooks/yookassa`, события `payment.succeeded`, `payment.canceled`, `refund.succeeded`.
4. Скопируйте shopId и секретный ключ.

## 6. Секреты в GitHub — ~10 минут
GitHub → репозиторий → Settings → Environments → **New environment `production`** → включите «Required reviewers» и выберите себя (без вашего нажатия ничего не выкатится).
Добавьте секреты окружения:
- `VPS_HOST` — IP сервера; `VPS_USER` — `root`; `VPS_PASSWORD` — пароль сервера (позже заменим на `VPS_SSH_KEY`);
- `PROD_ENV` — весь файл настроек. Шаблон — `.env.example`; Claude соберёт его для вас со всеми значениями, кроме секретов, а секреты (токены Google, бота, ЮKassa, JSON сервисного аккаунта) вы вставите сами.

## 7. Запуск
GitHub → Actions → **Deploy** → Run workflow → подтвердить. Первый запуск сам установит Docker, скачает код и поднимет сайт, бота и базу.

## Что делает Claude
- Код, тесты, конфиги, workflow, тексты гайдов и черновики юридических страниц.
- Создаёт и размечает Google-таблицы через подключённый Google Диск.
- Собирает `PROD_ENV` без секретов, проверяет после деплоя, что всё отвечает.
- Пушит в рабочую ветку только после вашего «можно», деплой — только по вашей команде.

## Образцы данных
Подключение к Google Диску отдаёт файл целиком прямо в контекст модели, поэтому экспорты на 20–90 МБ так прочитать нельзя. Решение — короткая ячейка для Colab, которая сохраняет рядом с каждым экспортом его «схему» (`*_schema.json`): структуру ключей, типы, счётчики и примеры дат **без текстов сообщений**. Эти файлы маленькие, и Claude прочитает их с Диска. Ячейка — в [samples-schema.md](samples-schema.md).
