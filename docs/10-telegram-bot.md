# 10. Telegram-бот

Тот же аккаунт, баланс и отчёты, что на сайте. Код — `apps/api/app/bot/__main__.py`, запуск `python -m app.bot` (v0.1 — long polling; прод — webhook, фаза 9).

## Команды
| Команда | v0.1 | Действие |
|---|---|---|
| `/start` | ✅ | приветствие, меню; `start=link_<token>` — привязка к аккаунту сайта |
| `/guide` | ✅ | TikTok / Telegram → шаги гайда из `docs/guides` |
| `/remind` | ✅ | напоминание о выгрузке TikTok: через 24 ч / 48 ч / завтра в 19:00 (пояс пользователя) / не напоминать |
| `/balance` | ✅ | баланс, покупка 5 разборов за ⭐ |
| `/promo КОД` | ✅ | промокод |
| `/privacy` | ✅ | что происходит с файлами |
| документ / альбом | ⏳ | фаза 9: приём файлов (локальный Bot API до 2 ГБ), Python-парсер, склейка альбома TikTok-файлов, галочки сводок inline-кнопками, отчёт ссылкой + PDF |
| Mini App | ⏳ | фаза 9: тот же фронтенд, вход по `initData` (проверка уже написана: `verify_webapp_init_data`) |

## Напоминания
Таблица `reminders`; бот раз в минуту отправляет созревшие: «Пора проверить выгрузку TikTok…» + кнопка «Ещё не готово — завтра». Позже: «пора обновить историю» через ~5 месяцев после загрузки (TikTok хранит ~6 месяцев), тихие часы 23:00–09:00.

## Хранение выгрузок в «Избранном»
Подсказка в гайде TikTok: держите свои выгрузки в «Избранном» Telegram и пересылайте боту одним сообщением — бот склеит (фаза 9).

## Уведомления админу (⏳ фаза 10)
Новые оплаты, ошибки уровня ERROR (с `request_id`), подозрение на перебор промокодов, сводка дня в 10:00.

Замедления Telegram в РФ → сайт остаётся основным каналом. Цифровые товары в боте — только за Stars.
