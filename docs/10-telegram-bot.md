# 10. Telegram-бот

Бот — второй вход в то же приложение: тот же аккаунт, тот же баланс разборов, те же отчёты.

## Команды и меню
| Команда | Действие |
|---|---|
| `/start` | приветствие, привязка аккаунта (`start=link_<token>`), кнопки: «Открыть приложение» (Mini App), «Гайд экспорта», «Напоминания», «Баланс» |
| `/guide` | выбор: TikTok / Telegram → пошаговый гайд (те же тексты, что на сайте, с картинками) |
| `/remind` | напоминания о выгрузке TikTok |
| `/balance` | баланс разборов, кнопка покупки за Stars |
| `/history` | сводка сохранённой TikTok-истории, удалить историю |
| `/reports` | последние отчёты со ссылками |
| `/promo <код>` | ввести промокод |
| `/settings` | часовой пояс, тихие часы, язык |
| `/privacy` | что происходит с файлами |
| `/delete_me` | удалить данные |

## Загрузка файлов
- Пользователь присылает документ (`result.json`, `user_data_tiktok.json`, `.zip`) или альбом документов (до 10).
- Ограничение стандартного Bot API — скачивание до **20 МБ**. Поэтому на VPS поднят **локальный сервер `telegram-bot-api`** (лимит до 2000 МБ). После обработки файл удаляется с его диска (`deleteFile` недоступен — чистим каталог сервера по `file_path` и cron-очисткой каждые 10 мин).
- Перед первой загрузкой — предупреждение: «Через бота файл обрабатывается на нашем сервере в памяти и удаляется сразу после подсчёта. Если хотите, чтобы файл не покидал устройство, — откройте приложение (кнопка)».
- Python-парсер → нормализованная модель → бесплатные сводки сообщением → кнопки: «Выбрать сводки» (inline-клавиатура с галочками ☑️/⬜) → «Сделать разбор (1 из N)».
- Отчёт присылается ссылкой на веб-версию + PDF-файлом + 3 PNG-карточками (по желанию).

### Склейка TikTok через бота
- Альбом из нескольких файлов → каждый парсится → `POST`-эквивалент склейки в сервисе истории → ответ: «Склеено 3 выгрузки: 61 245 просмотров за 14 мес. (дубликатов: 9 812)».
- Подсказка автора: хранить свои выгрузки в «Избранном» Telegram и пересылать их боту одним сообщением — выводится в гайде TikTok.
- Одинаковый файл повторно — распознаётся по `file_hash`, не дублирует.

## Напоминания (по желанию)
1. После гайда TikTok кнопка **«Я запросил выгрузку»** → «Когда напомнить?»: через 24 ч / через 48 ч / завтра в 19:00 / не напоминать.
2. В срок: «Проверьте TikTok → Настройки → Аккаунт → Скачать данные → вкладка „Скачать“. Файл доступен несколько дней» + кнопки «Готово, загружаю» / «Ещё не готово — напомнить завтра» / «Отключить».
3. После успешной загрузки истории — предложение: «Напомнить обновить историю через 5 месяцев, чтобы старые просмотры не потерялись?» (TikTok хранит ~6 мес.).
- Тихие часы 23:00–09:00 по часовому поясу пользователя; задачи — cron в worker каждую минуту по `reminders.due_at`.
- Всё логируется: `reminder.created/sent/clicked/disabled`.

## Mini App
- Тот же React-фронтенд (`/tg` роут), авторизация по `initData`. Файл выбирается через `<input type=file>` и обрабатывается в браузере — рекомендуемый путь для больших чатов.
- Тема Mini App подстраивается под тему Telegram (`themeParams`), но палитры приложения доступны.

## Уведомления админу
Отдельный приватный чат/канал админа: новые оплаты, ошибки уровня ERROR (с `request_id`), подозрения на перебор промокодов, ежедневная сводка в 10:00 (новые пользователи, разборы, выручка).

## Риски
- Замедления/блокировки Telegram в РФ → сайт остаётся основным каналом; бот не единственная точка оплаты.
- Правила Telegram о цифровых товарах → только Stars внутри бота.
