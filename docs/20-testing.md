# 20. Тестирование

## Данные для тестов
- **Реальные образцы** автора — только в `samples/` (gitignore) и на Google Диске в приватной папке. Используются вручную для сверки форматов, **никогда** не попадают в тесты в репо.
- **Синтетические фикстуры** `fixtures/` — генератор `fixtures/generate.py` (детерминированный seed):
  - `tg_personal_small.json` (2 участника, 2 000 сообщений, все типы медиа, реакции, удалённый аккаунт, `text` списком);
  - `tg_group.json` (12 участников, смена названий, приглашения, пересылки);
  - `tg_full_export.json` (`chats.list`);
  - `tt_export_a.json`, `tt_export_b.json` (перекрывающиеся периоды, повторные просмотры одного видео — проверка дедупликации по `(Date, Link)`), с чатами;
  - `tg_large.json` — 1 млн сообщений (генерируется на лету, не коммитится) для нагрузочного теста.
  - Тексты фикстур — из словаря нейтральных фраз + заранее известное число матов/имён/смеха (ожидаемые значения записаны рядом в `*.expected.json`).

## Уровни
| Уровень | Что | Инструмент |
|---|---|---|
| Юнит TS | парсеры, бесплатные метрики, сборщик пакета, нормализация текста | Vitest |
| Юнит Python | парсеры, платные метрики, ledger, промокоды, словари, scrub логов | pytest |
| Паритет | TS и Python дают одинаковый пакет на каждой фикстуре | pytest + node-скрипт |
| Golden-метрики | метрики на фикстурах = `*.expected.json` | pytest |
| API | сценарии с тестовой БД (pytest + httpx), моки ЮKassa/Google | pytest |
| Конкурентность | 20 параллельных `POST /runs` при балансе 1 → ровно 1 успешный | pytest-asyncio |
| Отчёт | рендер всех сводок; Playwright-скриншоты 360/768/1280, нет горизонтального скролла; PDF открывается | Playwright |
| E2E | вход (мок Google) → загрузка → бесплатное → промокод → разбор → PDF | Playwright |
| Бот | хендлеры с фейковыми апдейтами (aiogram test utils) | pytest |
| Приватность | «ядовитые» строки не попадают в логи, Sheets, пакет | pytest + vitest |
| Нагрузка | парсинг 300 МБ в воркере < 30 с на средней машине, память < 1.5 ГБ | Playwright + perf |

## Правило
Каждая новая метрика = фикстура с ожидаемым значением + golden-тест (скилл `add-metric`).
