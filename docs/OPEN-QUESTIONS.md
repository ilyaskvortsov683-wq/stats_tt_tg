# Открытые вопросы к автору

По каждому — вариант по умолчанию, с которым исполнитель будет работать, пока нет ответа.

| # | Вопрос | По умолчанию |
|---|---|---|
| 1 | **Название сервиса** | рабочее `stats_tt_tg`; варианты: «Разбор», «Переписка в цифрах», «Чатометр», «Wrapped.chat» (проверить домены и товарные знаки) |
| 2 | **Как назвать единицу оплаты** | «разбор». Альтернативы: «заход», «скан», «вспышка», «линза», «кадр». Меняется в `config/products.yaml` |
| 3 | Цена в Stars за пакет «5 разборов» | 150 ⭐ (сверить курс перед запуском) |
| 4 | Повтор того же чата бесплатен N дней | 30 |
| 5 | Налоговый режим на старте | НПД (самозанятость) до проверки спроса → ИП УСН 6% при росте. Влияет на чеки и выбор ЮKassa/Robokassa |
| 6 | Платёжный агрегатор | ЮKassa (интерфейс позволяет сменить на Robokassa) |
| 7 | Нужен ли анализ без входа (для конверсии) | нет, вход обязателен (`FREE_REQUIRES_LOGIN=true`) |
| 8 | Резервный вход, если Google недоступен пользователю | Telegram-вход; Яндекс ID позже |
| 9 | Что ещё в бесплатной части TG, кроме числа сообщений | только `tg.overview` + 1 карточка; активность по дням — платно |
| 10 | Стартовый список мата и имён | автор заполняет таблицу `dictionaries` (из своего файла мата); Claude готовит seed-CSV с базовыми именами |
| 11 | Где VPS | Timeweb Cloud (простая панель, S3 там же) |
| 12 | Хранить отчёты | 90 дней |
| 13 | Нужны ли английский интерфейс и международные платежи | нет в v1 |
| 14 | Порог паузы для «кто пишет первым» и разрыва TikTok-сессии | 6 ч и 5 мин |
| 15 | Показывать имена в отчёте по умолчанию | да, с переключателем «Скрыть имена» |
