# 12. Дизайн-система

Цель — «аккуратно и с характером», а не типовой интерфейс с фиолетовыми градиентами и карточками со скруглением 24px. Ориентир — редакционная инфографика (журнальные разборы данных): крупная типографика, много воздуха, мало декора, цифры — главные герои.

При любой работе над UI и отчётом загружать проектный скилл `design-system` и скилл `dataviz` (для графиков).

## Принципы
1. **Цифра — герой.** KPI крупно, моноширинные цифры (`font-variant-numeric: tabular-nums`).
2. **Заголовок-вывод** над каждым графиком: «Вы пишете первой в 64% случаев», мелко под ним — что изображено.
3. **Один акцент на экран.** Цвет — для смысла (участник, выделение), не для украшения.
4. **Тонкие линии, без теней.** Разделители 1px, тени только у всплывающих слоёв.
5. **Сетка 8px**, контейнер до 1120px, колонка текста до 680px.
6. **Без эмодзи в интерфейсе** (кроме данных пользователя — реакции, эмодзи-статистика).
7. **Микроанимации** ≤ 200 мс, отключаются при `prefers-reduced-motion`.

## Типографика (все шрифты OFL, с кириллицей, самохостинг)
| Роль | Шрифт | Где |
|---|---|---|
| Дисплей | **Unbounded** (600) | крупные числа на карточках, заголовки отчёта |
| Текст | **Onest** (400/500/600) | интерфейс, подписи |
| Цифры/код | **JetBrains Mono** (400/600) | таблицы, KPI-подписи, даты |

Шкала: 12 / 14 / 16 / 20 / 24 / 32 / 48 / 72. Межстрочный 1.5 для текста, 1.1 для дисплея.

## Токены
`packages/design-tokens/tokens.json` → CSS-переменные. Семантические имена, не «blue-500».

```
--bg, --surface, --surface-2, --border, --text, --text-muted, --text-faint,
--accent, --accent-contrast, --positive, --negative, --warning,
--series-1 … --series-8,            /* категориальные цвета участников */
--seq-0 … --seq-8,                  /* последовательная шкала для тепловых карт */
--radius-s: 6px; --radius-m: 10px; --radius-l: 16px;
--font-display, --font-text, --font-mono
```

## Темы и палитры
Три режима в переключателе: **Светлая**, **Тёмная**, **Палитры** (авторские сочетания, у каждой есть светлый и тёмный вариант). Значения ниже — стартовые; перед внедрением прогнать валидатор контраста из скилла `dataviz` (AA для текста, различимость серий, в т.ч. при дальтонизме).

| Палитра | Настроение | bg | text | accent | series-1 / series-2 |
|---|---|---|---|---|---|
| **Бумага** (светлая по умолчанию) | тёплый белый, чернила | `#F7F5F0` | `#1C1B19` | `#D2462C` | `#2F5D8A` / `#D2462C` |
| **Графит** (тёмная по умолчанию) | глубокий графит | `#121316` | `#ECEBE7` | `#F2A541` | `#7FB2E5` / `#F2A541` |
| **Мох** | приглушённо-зелёная, спокойная | `#EEF0E8` | `#1E241C` | `#4E7D3A` | `#4E7D3A` / `#B5651D` |
| **Терракота** | тёплая, глиняная | `#F4ECE4` | `#2A1E18` | `#B4532A` | `#B4532A` / `#3B6E74` |
| **Сумерки** | тёмно-синий с сиренью | `#161827` | `#E7E6F2` | `#B49BFF` | `#B49BFF` / `#5ED3C2` |
| **Плёнка** | высокий контраст, ч/б + один цвет | `#FFFFFF` | `#000000` | `#FF3B1F` | `#000000` / `#FF3B1F` |

Каждая палитра определяет полный набор токенов (8 серий, 9 ступеней последовательной шкалы). Участникам чата цвета назначаются стабильно: `p0 → series-1`, `p1 → series-2`.

## Компоненты (минимальный набор)
Button (primary/secondary/ghost), IconButton, Checkbox-карточка сводки (с замком), Tabs, Dropzone, Stepper (гайды), Progress (определённый/неопределённый), KPI, ChartFrame (заголовок-вывод + подпись + легенда + «скачать PNG»), Table (липкий заголовок, мобильный режим), Toast, Dialog/Sheet, ThemeSwitcher, Badge (бесплатно / разбор / бета), EmptyState.

Иконки — Lucide (тонкие 1.5px), только где помогают.

## Графики (общие правила, детали — скилл dataviz)
- SVG, без сторонних библиотек в отчёте. Оси тонкие, сетка горизонтальная еле заметная (`--border` с прозрачностью).
- Подписи дат по-русски: «янв», «фев»…; числа с неразрывным пробелом-разделителем тысяч: `48 312`.
- Столбцы по дням: окраска по дню недели — выходные акцентом, будни нейтральные (а не 7 цветов радуги).
- Тепловая карта «час × день»: последовательная шкала `--seq-*`, подписи часов через 3.
- Тултипы в веб-версии; в PDF/PNG — ключевые значения подписаны прямо на графике.
- Легенда — прямые подписи у линий, где возможно.

## Шаринг-карточки (PNG 1080×1920 и 1080×1080)
Одна мысль на карточку: большое число (Unbounded 160–220px), подпись-вывод, мини-график, водяной знак внизу. 3–5 шаблонов: «Всего сообщений», «Кто пишет первым», «Ночные совы», «Экранное время TikTok», «Самый жаркий день».
